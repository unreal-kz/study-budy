# ADR 0001: Хостинг для FastAPI-бэкенда (ST-27)

Дата: 2026-09-28. Статус: принято.

## Контекст

`server/` — тонкий stateless-прокси на FastAPI перед OpenRouter (`GET /health`, `POST /buddy/chat`), без БД, без фоновых задач, без вебсокетов. Нужен $0-хостинг для беты (один пользователь — Дарын), задеплоенный из GitHub, с поддержкой секретов (`OPENROUTER_API_KEY`) и без входа по карте, если возможно.

## Рассмотренные варианты

Актуальность проверена веб-поиском на 2026-09-28, не по памяти (бесплатные тарифы у хостингов меняются часто).

| Хостинг | Карта нужна? | Free-лимит | Cold start | Вердикт |
|---|---|---|---|---|
| **Render (free web service)** | Нет | 750 instance-hours/мес, 512MB RAM, 0.1 CPU, 100GB bandwidth | Сон через 15 мин простоя, разогрев 30–60с | **Выбран** |
| Fly.io | Да | Бесплатного тарифа больше нет с 2024 — только free trial (2 VM-часа / 7 дней), дальше от ~$5/мес | — | Отклонён — не $0 |
| Railway | Нет (Free plan), да для полноценного Trial | Free plan = $1 кредита/мес, 0.5GB RAM, 1 vCPU — по независимым источникам едва хватает на лёгкий сервис 24/7, оценки расходятся | Не документировано | Отклонён — слишком тонкий и неопределённый лимит для продакшен-беты |
| Google Cloud Run | С 3 февраля 2026 требует включённый billing (карту) даже для Always Free | Очень щедрый (2M запросов/мес), но требует карту + GCP-аккаунт | Быстрый (serverless) | Отклонён — карта + сложность GCP не оправданы для pet-проекта на двоих |

## Решение

**Render**, free web service tier.

- Без карты — минимальный порог входа для беты.
- 750 instance-hours/мес с запасом покрывает низкий трафик одного пользователя.
- Секреты — через Render Dashboard → Environment (`OPENROUTER_API_KEY`), не коммитятся.
- Деплой — подключение GitHub-репозитория, авто-деплой на push в `main` (или отдельная ветка/`render.yaml`, уточняется в ST-29).

## Последствия

- **Cold start 30–60с** — первый запрос `/buddy/chat` после простоя будет заметно медленным. ST-30 (release-сборка Flutter) уже учитывает это отдельным пунктом («таймаут под cold start») — нужен loading-индикатор и таймаут ≥60с на клиенте, не 10–15с по умолчанию.
- Если трафик вырастет за пределы одного пользователя — пересмотреть (Render платный tier или другой хостинг), это не постоянное архитектурное решение, а решение под текущий масштаб.
- CORS/токен-защита эндпоинта — отдельная задача ST-28, blocked-by этой ADR не является, идёт параллельно.

## Источники (веб-поиск 2026-09-28)

- Render: free tier limits, spin-down 15 мин, no-card confirmed по нескольким независимым источникам сентября 2026.
- Fly.io: free allowances убраны для новых аккаунтов с 2024, официальная документация по free trial (2 VM-часа/7 дней).
- Railway: официальная `docs.railway.com/pricing/plans` — Free plan $1/мес кредита, Trial $5 одноразово, sleep/env vars в документации не описаны явно.
- Google Cloud Run: `cloud.google.com/run/pricing` + сторонние обзоры — Always Free 2M requests/мес, но billing обязателен с 2026-02-03.
