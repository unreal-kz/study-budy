# Установка Study Buddy (бета)

## Установка APK

1. Скачай файл `study-buddy.apk`, который тебе прислали.
2. Открой его на телефоне. Android спросит разрешение на установку — если это первая установка не из Google Play, появится предупреждение «Из соображений безопасности телефон запрещает установку приложений из этого источника».
3. Нажми **Настройки** в этом диалоге → включи **Разрешить из этого источника** (для приложения, через которое открывал файл — браузер, Telegram и т.п.) → вернись назад и нажми **Установить**.
4. После установки APK можно (необязательно) снова выключить это разрешение в Настройках → Приложения → [то приложение] → Установка неизвестных приложений.

## Первый запуск

- Пройди короткий онбординг (уровень английского и т.п.).
- Первое сообщение в **AI Buddy** может идти **до минуты** — бесплатный сервер «засыпает» после простоя и должен «проснуться». Это нормально, приложение покажет полоску загрузки и подсказку «Waking up your buddy…». Все следующие сообщения будут быстрее, пока не пройдёт ~15 минут без использования.
- Если вместо ответа появилась ошибка — попробуй отправить сообщение ещё раз через минуту.

## Если что-то не работает

Напиши Baubek — скажи, что конкретно делал(а) и что видишь на экране (лучше со скриншотом).
